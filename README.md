# Juniper VLAN Cleaner & Auditor (`vlan-juniper`)

Python-утилита для автоматического поиска пустых («мертвых») VLAN без изученных MAC-адресов на коммутаторах **Juniper Networks** (серии **QFX** и **EX**) и безопасной генерации команд удаления и восстановления конфигурации.

---

## 🚀 Основные возможности

1. **Поиск неактивных VLAN:**
   * Анализирует таблицу коммутации (`show ethernet-switching table`) и находит все настроенные VLAN, на которых в данный момент нет ни одного MAC-адреса.
   * Корректно извлекает оригинальные описания (`description`) VLAN из конфигурационной базы (`show configuration vlans`).

2. **Кросс-версионность (ELS и legacy Junos):**
   * Поддерживает современную архитектуру **Junos ELS** (Enhanced Layer 2 Software — QFX5100, QFX5200, EX4300, EX4600 и др.).
   * Поддерживает классический формат **Junos non-ELS** (EX2200, EX3300, EX4200).
   * Автоматически адаптируется под разный уровень вложенности JSON в разных версиях Junos (Junos 14.x, 18.x, 21.x, 23.x+).

3. **Безопасное удаление в формате `display set`:**
   * Определяет все физические интерфейсы и агрегированные каналы (LAG / `ae`), в которые включен пустой VLAN.
   * Генерирует команды удаления с портов:  
     `delete interfaces <интерфейс> unit 0 family ethernet-switching vlan members <VLAN>`
   * Генерирует команду удаления самого VLAN:  
     `delete vlans <vlan_name>`
   * Группирует команды по каждому VLAN и разделяет их абзацами для удобного ручного копирования в терминал коммутатора.

4. **Команды быстрого отката (ROLLBACK / ВЕРНУТЬ НАЗАД):**
   * Для каждого удаляемого VLAN автоматически формируются команды `set` (с описанием, ID и всеми привязанными интерфейсами), что позволяет моментально вернуть конфигурацию назад в случае необходимости.

5. **Автоматическое журналирование в файл (`sw<IP>.txt`):**
   * При генерации команд удаления скрипт сохраняет их в отдельный текстовый файл, имя которого формируется по последнему октету IP-адреса коммутатора (например, для `192.168.55.200` $\to$ `sw200.txt`).
   * В начале файла фиксируются дата, время и параметры устройства.

6. **Гибкий список исключений (`exclude_vlans.txt`):**
   * Позволяет исключить служебные, резервные или управляющие VLAN из всех проверок и генерации команд удаления.

## 📋 Требования

* Python 3.8+
* Библиотека `netmiko`

Установка зависимостей:
```bash
pip install netmiko
```

---

## ⚙️ Настройка

Откройте файл `find_empty_vlans.py` и задайте параметры подключения в словаре `DEVICE`:

```python
DEVICE = {
    "device_type": "juniper_junos",
    "host": "192.168.55.200",               # IP-адрес вашего коммутатора
    "username": "Maks",                     # Логин SSH
    "use_keys": True,                       # Использовать SSH-ключ
    "key_file": "/home/maks/.ssh/id_rsa",   # Путь к приватному SSH-ключу
    # Для совместимости со старыми релизами Junos / OpenSSH:
    "disabled_algorithms": {"pubkeys": ["rsa-sha2-256", "rsa-sha2-512"]},
}
```

> [!NOTE]
> Параметр `disabled_algorithms` гарантирует корректную авторизацию по RSA-ключам даже на старых релизах Junos со встроенным OpenSSH 6.x.

---

## 🚫 Файл исключений (`exclude_vlans.txt`)

В файл `exclude_vlans.txt` построчно вносятся номера или имена VLAN, которые нужно игнорировать при аудите. 
Строки, начинающиеся с `#`, считаются комментариями.

Пример `exclude_vlans.txt`:
```text
# Исключения VLAN
1
default
4095
vlan21
100
```

## 💻 Использование

Запустите скрипт:
```bash
python3 find_empty_vlans.py
```

Скрипт подключится к коммутатору, соберет данные и предложит интерактивное меню:

```text
==================================================
ВЫБЕРИТЕ ДЕЙСТВИЕ:
  1. Вывести VLAN без MAC-адресов
  2. Вывести команды удаления (delete)
  0. Выход
==================================================
Ваш выбор [1/2/0]: 
```

### Режим 1: Вывод таблицы пустых VLAN
Выводит отсортированную таблицу VLAN, на которых не обнаружено активности:

```text
================================================================================
VLAN ID    | VLAN NAME                 | DESCRIPTION
================================================================================
65         | vlan65                    | BGP-sw204-sw42
66         | vlan66                    | Flowspec-Wanguard
125        | vlan125                   | Alef-QINQ
126        | vlan126                   | Cogent_HK_4_Alef
200        | vlan200                   | DTS
1011       | vlan1011                  | Privat-Kiev-Hls
...
================================================================================
Всего пустых VLAN: 18
```

### Режим 2: Вывод команд удаления
Выводит команды `delete` на экран и записывает подробный лог с командами удаления и восстановления в файл `sw<последний_октет>.txt`:

```text
# VLAN 65 (vlan65) - BGP-sw204-sw42
delete interfaces ae1 unit 0 family ethernet-switching vlan members 65
delete interfaces et-0/0/17 unit 0 family ethernet-switching vlan members 65
delete vlans vlan65

# VLAN 125 (vlan125) - Alef-QINQ
delete interfaces ae1 unit 0 family ethernet-switching vlan members 125
delete interfaces et-0/0/17 unit 0 family ethernet-switching vlan members 125
delete interfaces et-0/0/35 unit 0 family ethernet-switching vlan members 125
delete vlans vlan125
```

### Быстрый запуск без меню:
Можно передать номер действия сразу в аргументах запуска:
```bash
python3 find_empty_vlans.py 1   # Таблица пустых VLAN
python3 find_empty_vlans.py 2   # Генерация команд удаления
```

## 📄 Формат файла отчета (`sw<IP>.txt`)

При запуске режима 2 файл `sw200.txt` сохраняет структуру:

```text
================================================================================
# УСТРОЙСТВО: sw200 (192.168.55.200)
# ДАТА И ВРЕМЯ ГЕНЕРАЦИИ: 2026-10-06 10:52:19
# ВСЕГО ПУСТЫХ VLAN ДЛЯ УДАЛЕНИЯ: 18
================================================================================

# ------------------------------------------------------------------------------
# VLAN 65 (vlan65) - BGP-sw204-sw42
# ------------------------------------------------------------------------------
delete interfaces ae1 unit 0 family ethernet-switching vlan members 65
delete interfaces et-0/0/17 unit 0 family ethernet-switching vlan members 65
delete vlans vlan65

# Команды для восстановления (ROLLBACK / ВЕРНУТЬ НАЗАД):
set vlans vlan65 vlan-id 65
set vlans vlan65 description "BGP-sw204-sw42"
set interfaces ae1 unit 0 family ethernet-switching vlan members 65
set interfaces et-0/0/17 unit 0 family ethernet-switching vlan members 65
```

## ⚠️ Важное замечание по rate-limit SSH

На некоторых коммутаторах Juniper настроен лимит новых SSH-соединений:
`system services ssh rate-limit 3;` (не более 3 новых подключений в минуту). 
Скрипт оптимизирован и выполняет все операции **за одну SSH-сессию**. Однако при повторных запусках скрипта подряд рекомендуется выдерживать паузу в 15–20 секунд во избежание сброса соединений со стороны коммутатора.
